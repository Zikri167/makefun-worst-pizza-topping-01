**$2 over 10 places** — an entry in make.fun's [The Worst Pizza Topping bounty](https://make.fun/bounty/u-motasimfuad-the-worst-pizza-topping-062c6893).

A minimal Node script imports the built-in `fs` module and synchronously writes a hard-coded string to the file `/output/entry.txt` using `fs.writeFileSync`, ensuring deterministic output on every run. By placing the joke text as a literal in the source and invoking the script with `node main.ts`, the program creates the required one-line entry without any randomness or external dependencies.
